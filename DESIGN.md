# Booth visual

Alat, bukan halaman iklan. Latar gelap karena panggung kamera memang hitam. Strip kertas krem cuma di hasil cetak, bukan latar situs.

- Latar: `#121417`
- Permukaan: `#1c2128`
- Teks: `#f3efe8`
- Teks redup: `#b7b1a8`
- Garis: `#343b44`
- Aksen: `#c4271b` (tombol utama, teks putih)
- Kertas strip: `#f4f1ea`
- Tinta di kertas: `#1a1814`

Sudut: 16px untuk panel dan video. Tombol pill. Satu aksen merah di seluruh alat.

Gerak: flash putih singkat dan tombol mengecil saat ditekan. `prefers-reduced-motion` mematikan transisi flash. Hitung mundur tetap ada karena itu informasi, bukan hiasan.

Tombol jepret di bawah video, tidak menutup muka.

Mode terang tidak dibuat. Seluruh alat sudah mode gelap.
